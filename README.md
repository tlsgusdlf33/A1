# 이력서 자동 갱신 시스템

신현일 / tlsgusdlf33@gmail.com

Google Drive의 실제 업무 기록을 근거로 이력서·자기소개서를 **주기적으로 갱신**하고,
채용 단계의 **AI 작성 검증(GPT킬러 등)에 대응**하기 위한 저장소입니다.

## 구성

| 경로 | 내용 |
|---|---|
| `resume/변경제안_YYMMDD.md` | 갱신 실행 결과. 무엇을 어떻게 바꿀지 근거와 함께 제안 |
| `data/프로젝트_이력.tsv` | 근거 데이터. `내 노트북 > 01 도서 > {연도}` 폴더에서 추출한 프로젝트 실적 |
| `docs/AI검증_대응_가이드.md` | AI 작성 판별 원리와 대응 원칙, 제출 전 점검표 |

## 데이터 흐름

```
Google Drive                                   이 저장소
─────────────────────────────                  ──────────────────────
내 컴퓨터 > 내 노트북 > 01 도서 > 2026/  ──┐
                                  2025/  ──┼──▶  data/프로젝트_이력.tsv
                                                      │
업무 > 이력서 > 한화에어로스페이스-E&C(기계).txt ──┐  │
  (현재 마스터 원고)                            │  │
                                               ▼  ▼
                                    resume/변경제안_YYMMDD.md
                                    (신규 실적 · 문구 수정안 · 검증 항목)
```

**원칙: 이 저장소는 이력서를 직접 고쳐 쓰지 않습니다.**
최종 원고는 본인이 직접 반영합니다. 이유는 두 가지입니다.

1. 사실 확인은 본인만 가능합니다 (수주 여부, 실제 건수, 공개 가능 범위)
2. AI가 쓴 문장을 그대로 제출하는 것이 탐지 위험의 핵심입니다
   (`docs/AI검증_대응_가이드.md` 원칙 2·3 참조)

## 주기적 갱신

매월 1일 09:00(KST)에 세션이 자동 실행되어 다음을 수행합니다.

1. `내 노트북 > 01 도서 > {올해}` / `{작년}` 폴더 스캔
2. `data/프로젝트_이력.tsv`와 대조해 **신규 프로젝트 추출**
3. 신규 건이 현재 이력서에 반영할 가치가 있는지 판단
   (해외 / 신사업 영역(수소·연료전지·원자력·반도체) / 신규 고객사 / 신규 품목 우선)
4. 변경이 있으면 `resume/변경제안_YYMMDD.md` 생성 후 커밋·푸시
5. 변경이 없으면 아무것도 하지 않음

수동 실행이 필요하면 이 세션에 "이력서 갱신 확인해줘"라고 말하면 됩니다.

## 현재 마스터 원고

`업무/이력서/한화에어로스페이스-E&C(기계).txt` (Drive, 최종 수정 2026-08-31)

한화에어로스페이스 E&C(기계) 지원용으로 작성된 문서이며,
이력서·자기소개서·경력기술서가 한 파일에 모두 들어 있습니다.
**다른 회사 지원 시 회사명 5곳과 직무 연계 단락을 반드시 교체**해야 합니다.
